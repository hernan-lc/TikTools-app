# Universal Widget SDK 1.0.0

Protocol 1, manifest 3 (`contract: universal-widget`), portable project/preset 1.
Framework-neutral browser modules, shared JSON Schemas, native schema data and
offline fixtures. The OBS plugin needs no JavaScript toolchain at runtime.

- `index.js`: validation, native/TikTools normalization, bounded routing, lifecycle.
- `editor.js`: tree/layout commands, history, presets, migrations, canonical JSON.
- `editor-ui.js`: portable panel embedded by React/Vue wrappers.
- `transport.js`: optional bounded HTTP producer bridge; OBS itself uses C++.
- `native.rs`, `schemas/native-schemas.hpp`: schema-backed native consumers.
- `fixtures/conformance.json`: the same acceptance corpus for JS, C++ and Rust.

Use `WidgetRuntime(widget,host,manifest)` with initialize/mount/updateSettings/
onEvent/dispose methods. Hosts explicitly advertise capabilities. Events arrive
on `universal:event` in OBS, or through the existing TikTools domain adapter.
Never subscribe to both native and canonical channels implicitly. Use
`fromTikTools` to convert `live.event` envelopes. Original upstream IDs and room
identity are preserved; absent IDs cannot establish cross-producer equivalence.

Supported schema vocabulary is intentionally bounded across all three languages.
Unsupported assertion keywords and external references fail package registration.
All schemas and mapping tables are generated by `tools/generate.mjs`; never edit
the generated schema/header data independently. `tools/sync.mjs` vendors the SDK
with SHA-256 checks into TikTools, whose build remains independent afterward.

Portable packages contain trusted compiled HTML/CSS/JS. Import the compiled folder
into either portable editor. Runtime compiler installation and dependency
resolution are unsupported. Original app editors and legacy widgets remain
available. Preview containment is not a hostile-author sandbox guarantee.

The implementation/release guide is `obs-tiktok-widgets/docs/UNIVERSAL_WIDGETS.md`.
Do not publish credentials in widget packages, URLs, project files or logs.
